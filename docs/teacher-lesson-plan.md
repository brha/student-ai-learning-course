# Student AI Learning Course - Teacher Lesson Plan

## Overview

This lesson plan follows a 4-week structure with 2 meetings per week and 3 lessons per meeting. Each lesson is 45 minutes long.

## Weekly Structure

### Week 1: Foundations of AI and data basics

#### Meeting 1

Lesson 1: What is AI, ML, and deep learning?
- Goal: Introduce key terms and examples
- Activity: Class discussion with real-world examples
- Homework: Write 3 everyday AI examples

Lesson 2: Python review for AI
- Goal: Refresh core Python concepts
- Topics: loops, dictionaries, functions, OOP basics
- Activity: Build a simple Student class

Lesson 3: Data basics
- Goal: Explain features, labels, training, testing
- Activity: Small dataset exercise

#### Meeting 2

Lesson 4: How does a model learn?
- Goal: Explain prediction and pattern recognition
- Activity: Predict house price from size example

Lesson 5: Mini project: rule-based chatbot
- Goal: Introduce AI without ML
- Activity: Build a simple Q&A chatbot

Lesson 6: Reflection and debugging
- Goal: Review code and improve chatbot logic
- Activity: Improve keywords and responses

### Week 2: Machine learning basics

#### Meeting 3

Lesson 7: Supervised learning introduction
- Goal: Explain classification and regression
- Activity: Classify fruit or email examples

Lesson 8: Data preprocessing
- Goal: Teach cleaning and feature preparation
- Topics: missing values, text cleaning, train/test split

Lesson 9: Intro to scikit-learn
- Goal: Show a complete ML workflow
- Activity: Train a logistic regression model

#### Meeting 4

Lesson 10: Build a simple spam detector or sentiment model
- Goal: Use text data for classification
- Activity: Create a tiny dataset and train a model

Lesson 11: Model evaluation
- Goal: Explain accuracy and confusion matrix
- Activity: Discuss what bad accuracy means

Lesson 12: Code lab
- Goal: Students test their own ideas
- Activity: Tune parameters and compare results

### Week 3: Neural networks and simple deep learning

#### Meeting 5

Lesson 13: Neural networks explained simply
- Goal: Explain neurons and layers
- Activity: Visual diagram and hands-on analogy

Lesson 14: Handwritten digit recognition
- Goal: Show a classic beginner project
- Activity: Introduce MNIST dataset

Lesson 15: Build a simple classifier with TensorFlow/Keras
- Goal: Train first neural network
- Activity: Use sample code and observe outputs

#### Meeting 6

Lesson 16: Image classification introduction
- Goal: Explain image datasets and processing
- Activity: Cat-vs-dog example

Lesson 17: Mini image classifier
- Goal: Train a basic model on small images
- Activity: Modify starter code

Lesson 18: Troubleshooting and model improvement
- Goal: Discuss overfitting and tuning
- Activity: Adjust epochs, layers, and data size

### Week 4: Final project and presentation

#### Meeting 7

Lesson 19: Project selection
- Goal: Students choose a project topic
- Options: chatbot, spam detector, sentiment analysis, digit recognition

Lesson 20: Project planning
- Goal: Students define the problem, dataset, and goal
- Activity: Write a short project brief

Lesson 21: Coding session 1
- Goal: Create the project skeleton and dataset

#### Meeting 8

Lesson 22: Coding session 2
- Goal: Improve the model or interface

Lesson 23: Presentation practice
- Goal: Prepare 3–5 minute demo
- Activity: Explain how the model works and what it predicts

Lesson 24: Final presentations
- Goal: Demo projects and reflect on learning

## Assessment Ideas

- Participation in class activities
- Short coding exercises
- Weekly reflection worksheet
- Final project demo
- One-page explanation of model behavior

## Common Teacher Tips

- Keep examples small and visual
- Use a single dataset repeatedly so students can understand it deeply
- Show code working before asking students to build from scratch
- Focus on understanding, not memorizing formulas
- Encourage experimentation

## Suggested Student Deliverables

- 3 short reflection notes
- 2 mini projects
- 1 final AI project
- 1 short presentation
