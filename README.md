# Student AI Learning Course

A 4-week beginner-friendly AI course for students who already know Python and object-oriented programming.

## Course Overview

This course introduces students to the basic concepts behind artificial intelligence and machine learning through short explanations, hands-on activities, and beginner projects.

- Format: 2 meetings per week
- Lesson length: 45 minutes
- Total: 4 weeks, 8 sessions, 24 lessons
- Tools: Python, Jupyter Notebook or VS Code, scikit-learn, pandas, matplotlib

## Learning Goals

By the end of the course, students should be able to:

- explain what AI, machine learning, and deep learning are
- describe how data is used to train a model
- build and test a simple classifier
- understand the difference between training and testing data
- create a small AI project in Python
- explain how a neural network works at a high level

## Recommended Tools

- Python 3.10+
- VS Code or Jupyter Notebook
- scikit-learn
- pandas
- matplotlib
- Optional: OpenCV, TensorFlow/Keras

## Weekly Flow

- Week 1: Foundations of AI and data basics
- Week 2: Machine learning basics and simple classifiers
- Week 3: Neural networks and introductory deep learning
- Week 4: Final project and presentation

1. Rule-based chatbot
2. Sentiment or spam detector
3. Digit recognizer
4. Final project

## Teacher Notes

Keep explanations visual and concrete. Students learn most when they see a model make a prediction on real data. Start with classification problems and avoid too much math early on.
