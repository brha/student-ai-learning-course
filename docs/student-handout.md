# Student AI Learning Handout

## What is AI?

Artificial intelligence is a field where computers are designed to do tasks that usually require human thinking, such as recognizing patterns, understanding text, or making decisions.

Examples:
- spam filters
- recommendation systems
- face detection
- voice assistants
- image classification

## What is machine learning?

Machine learning is a way for computers to learn patterns from data instead of being told every rule explicitly.

Example:
- A model sees many emails labeled as spam or not spam
- It learns which words or patterns appear in spam emails
- Later, it can classify new emails

## What is deep learning?

Deep learning is a type of machine learning that uses neural networks made of many layers. These networks are helpful for tasks like image recognition, spoken language, and text generation.

## Key ideas in AI

- Data: the information the model learns from
- Features: the measurable qualities the model uses
- Label: the output we want to predict
- Training: teaching the model from examples
- Testing: checking whether the model works on new data
- Accuracy: how often the model predicts correctly

## Python basics you should know

- variables
- loops
- functions
- lists and dictionaries
- classes and objects
- reading files

## Basic AI workflow

1. Gather data
2. Clean and prepare the data
3. Split the data into training and testing sets
4. Train a model
5. Test the model
6. Improve the model

## Common beginner projects

- simple chatbot
- spam detector
- sentiment analysis
- digit recognizer
- image classifier
- face detection

## Recommended order of learning

1. Python basics
2. AI concepts
3. Data and labels
4. Machine learning models
5. Neural networks
6. Final project

## Weekly checklist

### Week 1
- understand AI, ML, and deep learning
- review Python basics
- learn the difference between data, labels, and prediction

### Week 2
- learn classification
- train a simple model
- evaluate results

### Week 3
- understand neural networks
- train a simple image recognition model
- troubleshoot what goes wrong

### Week 4
- build a small final project
- present what your model does and how it works

## Good questions to ask

- What problem is the model solving?
- What data is used?
- What is the label?
- How is the model evaluated?
- What are the limits of the model?

## Final advice

Start small. The best way to learn AI is by building simple projects, seeing the model work, and then improving it.
